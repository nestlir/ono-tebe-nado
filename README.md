# Оно тебе надо — Editorial Web Layout

> Responsive editorial landing page focused on typography, composition and semantic HTML.

[**Live demo →**](https://nestlir.github.io/ono-tebe-nado/)

## Overview

A content-first landing page built around a restrained visual system. The key challenge was to reproduce a dense editorial composition while keeping the markup semantic, the CSS predictable and the experience responsive.

## What I demonstrated

- semantic HTML5 structure;
- responsive layout across viewport sizes;
- CSS Grid/Flexbox composition;
- typography and spacing as a visual system;
- image cropping and object positioning;
- reusable layout patterns;
- attention to pixel accuracy against the design.

## Engineering focus

The project demonstrates the frontend fundamentals I use when turning a visual specification into maintainable code: meaningful document structure, intentional layout primitives and preserved hierarchy across breakpoints.

## Stack

**HTML5 · CSS3 · responsive layout · Git**

